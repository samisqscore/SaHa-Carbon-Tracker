---

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you believe you have discovered a security vulnerability in the SaHa Carbon Footprint Tracker, please report it privately:

1. **GitHub Security Advisory**: Submit a private advisory directly via the repository's **Security** > **Advisories** tab.
2. Alternatively, email the maintainers with:
   - A description of the vulnerability.
   - Steps to reproduce or a Proof of Concept (PoC).
   - Potential impact on users or deployments.

### What to Expect
- You will receive an initial response acknowledging your report within 48–72 hours.
- We will coordinate remediation, test the patch, and release a fix alongside appropriate disclosure attribution.
- We kindly ask you to adhere to responsible disclosure guidelines and keep details private until a public patch is issued.
